# reservas-house

Practica Final del Bootcamp de Desarrollo Frontend Moderno

El proyecto consta de un sistema simple de reservas para el house del barrio en donde actualmente vivo, el mismo no tiene ningun sistema y no tienen una forma organizada de anotar los eventos que tienen proximamente asi como los clientes o presupuestos entregados.
La idea principal es ofrecer una pagina donde se puedan ver los eventos agendados y agendar nuevos, y si es posible dejar las bases para escalar el proyecto en el futuro para incluir una base de clientes y de presupuestos.

El proyecto se desarrollo con Vue y Typescript.

Al descargar el mismo se deberan ejecutar los siguientes comandos desde la terminal en el directorio del proyecto.

```console
npm install
```

```console
npm run dev
```

Luego en el explorador ir a: [http://localhost:5173/](http://localhost:5173/)
